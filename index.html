BREW Design System

Un sistema de diseño multi-marca para Convos y Growlat. Tokens semánticos, componentes PrimeVue 4 y guías de implementación en Vue 3 + Tailwind CSS.

Vue 3 PrimeVue 4 Tailwind CSS Poppins + Space Grotesk Multi-brand SemVer
Design Tokens
Paletas de color, semánticos y tokens brand que cambian por plataforma.
Typography
Space Grotesk para headers, Poppins para cuerpo. Escala 1rem = 16px.
Components
Buttons, inputs, badges, tablas, notas, drawers y más.
